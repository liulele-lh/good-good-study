把“战争—条约—中方代表”配成一组。下表分清签署代表、会办人员与作战将领；不是把所有参与过交涉的人都列为签字人。共7组条约。

1842年8月29日

《南京条约》

耆英、伊里布、牛鉴

耆英、伊里布是钦差代表；牛鉴是两江总督，也列名中方签约代表。

鸦片战争后的中方代表。对方是英国代表璞鼎查；李鸿章不是这份条约的签署人。

核对：南京条约史料陈列馆

1858年6月

《天津条约》各约

桂良、花沙纳

清政府派出的全权大臣，分别与俄、美、英、法代表订约。

属于第二次鸦片战争。它是一组分别签订的条约，不是四国在同一天合签一份。注意区别1885年的《中法新约》。

核对：故宫博物院相关词条

1860年

《北京条约》各约

奕訢（奕䜣），恭亲王

代表清政府分别与英、法、俄订立《北京条约》。

后来也是中央洋务派的重要代表。奕訢与1901年签《辛丑条约》的奕劻不是同一个人。

核对：恭王府博物馆 · 补充核对

1881年2月24日

《中俄伊犁条约》

曾纪泽

代表清政府赴俄交涉并签署改订条约。此条作为收复新疆的衔接补充。

左宗棠提供军事支撑，曾纪泽进行外交交涉。中国收回伊犁大部分地区，仍付出割地、赔款等代价，不能记成完全平等的条约。

核对：清远纪检监察网相关史料

1885年6月9日

《中法新约》／《越南条款》

李鸿章；锡珍、邓承修参与会办

李鸿章为主要谈判、签约代表；条约正文还列锡珍、邓承修为清方全权大臣。

中法战争结束后的条约。冯子材在镇南关指挥作战；李鸿章等办理议和。作战将领与签约代表要分开记。

核对：盐田区档案馆；条约原文转录 · 补充核对

1895年4月17日

《马关条约》

李鸿章、李经方

两人均为清方全权代表，参与谈判并签署条约。

甲午中日战争后签订。日方代表为伊藤博文、陆奥宗光。课堂常突出李鸿章，但中方签署代表不能只记他一人。

核对：国家文化记忆库；条约原文转录 · 补充核对

1901年9月7日

《辛丑条约》

奕劻（庆亲王）、李鸿章

两人作为清政府全权代表，与11国代表签署条约。

对应1900年八国联军侵华后的议和。奕劻不是奕訢；慈禧太后是清廷决策者，不是现场签约代表。

核对：深圳市盐田区档案馆

先记住这五组：南京——耆英、伊里布、牛鉴；天津——桂良、花沙纳；北京——恭亲王奕訢；马关——李鸿章、李经方；辛丑——庆亲王奕劻、李鸿章。
最易混：恭亲王奕訢 ≠ 庆亲王奕劻。“奕訢”与教材常见写法“奕䜣”指同一人。

用同一个人，把几件事串起来

李鸿章：洋务、海军与对外交涉

洋务派地方代表 → 1885《中法新约》 → 北洋海军建设 → 1895《马关条约》 → 1901《辛丑条约》

1894年，孙中山曾向他提出改革建议。同一人可以出现在工业建设、海军建设和对外交涉等不同事件里。不能因为他参与多份条约，就把《南京》《天津》《北京》都归到他名下。

奕訢：从北京议和到中央洋务

1860《北京条约》 → 1861总理衙门 → 中央洋务派代表

他是恭亲王奕訢（奕䜣）。清廷在北京议和之后，逐渐加强专门的外交事务管理，并开展洋务活动。他不是1901年《辛丑条约》的签署人。

奕劻：与李鸿章共同签署辛丑条约

1900侵华战争后的议和 → 1901奕劻、李鸿章签约

他是庆亲王奕劻。用封号区分：恭亲王—北京；庆亲王—辛丑。慈禧太后与清廷决策有关，不能因此把她写成现场签约代表。

左宗棠与曾纪泽：军事与外交相配合

左宗棠收复新疆大片领土 → 曾纪泽赴俄交涉 → 1881《伊犁条约》 → 1884新疆建省

左宗棠主要负责军事；曾纪泽是该约的中方谈判、签署代表。收复新疆不能只记成一次战役，解决伊犁问题也不能只归给某一人的军事行动。

《天津条约》各约签订

第二次鸦片战争期间签订的一组条约。不是由李鸿章签订，也不是四国同日合签一份。

《北京条约》各约签订

与1858年《天津条约》相衔接，使中国半殖民地化程度进一步加深。奕訢后来也是中央洋务派代表。
人物 / 角色
奕訢（奕䜣，恭亲王）：清方代表，分别与英、法、俄订约。

19世纪60—90年代

洋务运动

目的：学习西方先进技术，富国强兵，维护清王朝统治。前期“自强”，后期“求富”。

奕訢（奕䜣，恭亲王）：中央代表，也曾签《北京条约》；曾国藩、李鸿章、左宗棠、张之洞：地方代表。

19世纪60年代起

创办近代军事工业

代表企业：安庆内军械所、江南机器制造总局、福州船政局。侧重制造枪炮、舰船等。
人物 / 角色
曾国藩、李鸿章、左宗棠等洋务派官员：推动创办军事企业。
1861年

设立总理各国事务衙门

补充人物联系：奕訢从1860年北京议和，走到专门外交机构与洋务事务；他与1901年签辛丑条约的奕劻不是同一人。
人物 / 角色
奕訢、桂良、文祥等：推动设立并负责相关事务。
1865年

阿古柏入侵新疆

新疆边疆危机加剧，为理解后来左宗棠督办新疆军务提供背景。
人物 / 角色
阿古柏：入侵新疆；新疆各族人民：遭受侵略并进行抵抗。
19世纪70年代

民族资本主义兴起，商办企业出现

受外商企业刺激和洋务运动影响。不要把所有洋务企业直接等同于民族资本主义企业。
人物 / 角色
中国民族实业家：兴办近代商办企业。
洋务运动后期
19世纪70年代起

创办近代民用企业

代表：轮船招商局、开平煤矿、汉阳铁厂、湖北织布局。民用企业也为军工提供资金、原料与运输。
人物 / 角色
李鸿章、张之洞等洋务派官员：兴办航运、煤矿、钢铁、纺织等企业。
1871年

俄国出兵占领伊犁

与阿古柏入侵相联系，但不是同一事件。
人物 / 角色
俄国军队：占领伊犁；清政府：面临西北边疆危机。
1874年

日本侵略台湾

日本从中国勒索白银50万两，反映海防压力。
人物 / 角色
日本侵略军：进犯台湾；清政府：向日本赔款。
1875年起

左宗棠督办新疆军务、收复新疆

左宗棠负责军事行动；曾纪泽后来赴俄交涉，1881年签《伊犁条约》。军事收复与外交议约要联系起来，也要分清分工。
人物 / 角色
左宗棠：受命为钦差大臣，督办新疆军务，率军收复新疆大片领土。
1881年2月24日

《中俄伊犁条约》签订

为衔接边疆危机而补充。中国收回伊犁大部分地区，但仍付出割地、赔款等代价；1884年新疆建省是后续治理措施。
人物 / 角色
曾纪泽：清方谈判、签署代表；左宗棠等的军事准备：提供交涉支撑。
1883—1885年

中法战争

战争涉及越南及中国东南、西南边疆。下列1884、1885年的事件是这场战争中的具体节点。
人物 / 角色
法国：侵略一方；清军与中国军民：抵抗侵略。
1884年

新疆建省

加强中央对新疆的管辖，维护边疆稳定。不要把“建省”直接写成左宗棠个人宣布的行动。
人物 / 角色
清政府：设立新疆行省；左宗棠：此前收复新疆的重要推动者。
1884年

法军袭击福建水师、进犯台湾

与中法战争相联系，也说明海军建设与海防仍面临严峻挑战。
人物 / 角色
法国海军：发动袭击；福建水师与台湾军民：抵抗侵略。
1885年

镇南关大捷

冯子材指挥作战取得胜利；随后议和由李鸿章等办理，签订《中法新约》（《越南条款》）。将领与签约代表不是同一角色。
人物 / 角色
冯子材：指挥清军抗击法军，取得镇南关大捷。
1885年6月9日

《中法新约》（《越南条款》）签订

中法战争后的条约。冯子材—战场抵抗；李鸿章等—外交议和。与1858年《中法天津条约》不是同一份条约。
人物 / 角色
李鸿章：清方主要议和、签约代表；锡珍、邓承修：参与会办，列名清方全权大臣；巴德诺：法方代表。
1885年

台湾建省

加强台湾海防地位与管理。与新疆建省配对记：新疆1884、台湾1885。
人物 / 角色
清政府：建立台湾行省。
1888年

北洋舰队正式成军

北洋舰队是当时规模最大的一支中国海军力量。后来在甲午战争中全军覆没。
人物 / 角色
丁汝昌：北洋海军提督；李鸿章：北洋海军建设的重要推动者。

1894年

孙中山上书受挫，成立兴中会

孙中山由改革建议走向革命实践。兴中会是革命团体，不要与1905年的中国同盟会混淆。

甲午中日战争

主要战役：平壤、黄海、辽东半岛、威海卫。战争结果影响洋务、变法、实业与革命多条线索。
人物 / 角色
日本：发动侵略战争；清军与中国军民：抵抗。丁汝昌、邓世昌、左宝贵等参与作战。
1894年

平壤战役

“左宝贵—平壤”，不要与“左宗棠—新疆”混淆。
人物 / 角色
左宝贵：在平壤抵抗日军，壮烈牺牲。
1894年

黄海海战

邓世昌、林永升等英勇牺牲。黄海海战不等于北洋舰队最终全军覆没的威海卫战役。
人物 / 角色
丁汝昌：北洋海军提督；邓世昌：致远舰管带；林永升：经远舰管带。
1894年

辽东半岛战役、旅顺大屠杀

将人物的抗争与侵略军的暴行分清。
人物 / 角色
徐邦道等清军将领：抵抗日军；日本侵略军：制造旅顺大屠杀。
1895年

威海卫战役

北洋舰队全军覆没，标志着洋务运动破产；不能因此否定洋务运动对近代工业的作用。
人物 / 角色
丁汝昌及北洋舰队官兵：抗击日军。
1895年4月17日

《马关条约》签订

割地、赔款白银2亿两、开放沙市等四口、允许日本在通商口岸设厂。中国半殖民地化程度大大加深。
人物 / 角色
李鸿章、李经方：清方全权代表，参与谈判并签署；伊藤博文、陆奥宗光：日方全权代表。
1895年

公车上书

拉开维新运动序幕。公车上书在1895年，百日维新在1898年。
人物 / 角色
康有为、梁启超等：推动上书、反对条约，要求变法图强。
甲午战争后
19世纪末

列强掀起瓜分中国狂潮

争夺路矿利权、强租租借地、划分势力范围。“门户开放”意在分享在华利益，并非保护中国独立。
人物 / 角色
德、俄、法等列强：争夺权益；美国：随后提出“门户开放”照会。
甲午战争后

民族资本主义初步发展；实业救国

清政府放松民间设厂限制。民族工业以轻工业为主，资金少、规模小、分布不均衡。这里标的是发展阶段，非纱厂某一具体开工日。
人物 / 角色
张謇：创办大生纱厂，主张“实业救国”；民族实业家：发展工商业。
1895年

广州起义（兴中会时期）

起义失败。与1911年的广州黄花岗起义并非同一次。
人物 / 角色
孙中山：领导、筹划反清起义。
1895—1898年间

组织学会、办报与传播维新思想

宣传变法图强、救亡图存，为维新改革作思想和组织准备。此处用时段概括，不把各项活动当成同一年发生。
人物 / 角色
康有为：讲学、宣传变法；梁启超：在《时务报》发表《变法通议》；严复：主持《国闻报》、翻译《天演论》。
1898年6月

百日维新开始

政治、经济、教育、军事多方面改革；自上而下的资产阶级性质改良运动。
人物 / 角色
光绪帝：颁布“明定国是”诏书；康有为、梁启超等：推动变法。
1898年9月

戊戌政变，变法失败

改革历时103天，故称百日维新。失败不等于没有思想启蒙作用。
人物 / 角色
慈禧太后等：发动政变；康有为、梁启超：出逃；谭嗣同等“戊戌六君子”：遇害。

反帝斗争与辛丑条约1900—1901

反帝斗争与辛丑条约 · 4 条记录（长期运动与具体节点可能重叠）

1900年夏

义和团进入京津地区，开展反帝斗争

口号“扶清灭洋”体现反帝意志，也反映对清政府的幻想与盲目排外的局限。
人物 / 角色
义和团群众：主要反抗力量；清政府：与义和团关系复杂，最终参与镇压。
1900年6月起

八国联军侵华，廊坊等地发生抵抗

联军从天津向北京进犯。八个国家与后来的《辛丑条约》签约国数不能混为一谈。
人物 / 角色
英、美、法、德、俄、日、奥匈、意：组成联军；义和团等：抵抗侵略。
1900年8月

八国联军攻陷北京

义和团运动最终失败，清政府被迫接受更严重的不平等条约。
人物 / 角色
八国联军：占领北京；义和团运动：遭中外反动势力镇压。
1901年9月7日

《辛丑条约》签订

赔款4.5亿两、禁止反帝活动、驻兵、划使馆界等。清政府成为列强统治中国的工具，中国完全陷入半殖民地半封建社会的深渊。
人物 / 角色
奕劻（庆亲王）、李鸿章：清方全权谈判、签署代表；列强一方为11国代表。奕劻不是签《北京条约》的恭亲王奕訢。
04

革命准备与民国建立1905—1912

从革命组织、革命纲领，走到武昌起义与建立共和国。

革命准备与民国建立 · 11 条记录（长期运动与具体节点可能重叠）
时间点 / 时段关键事件 · 结果与联系参与人物 · 具体角色
1905年

中国同盟会在东京成立

第一个全国规模的、统一的资产阶级革命政党。机关报《民报》；纲领阐发为民族、民权、民生三大主义。
人物 / 角色
孙中山：革命领导人；兴中会、华兴会、光复会等团体成员：联合组党。
1905年

清政府废除科举制度

辨析补充：不是1898年“废除八股”，也不是1901年条约规定的有关地区停考5年。
人物 / 角色
清政府：推行教育制度变革。
1906—1911年4月

革命党人多次发动武装起义

多次起义虽未成功，却扩大革命影响。下一条黄花岗起义属于这一阶段。
人物 / 角色
孙中山、黄兴等革命党人：组织和领导武装斗争。
1911年4月

广州黄花岗起义

起义失败。收殓的72具烈士遗骸葬于黄花岗，史称“黄花岗七十二烈士”。
人物 / 角色
孙中山、黄兴：领导此次起义；革命烈士：英勇牺牲。
1911年10月10日

武昌起义

武昌起义成功，武汉三镇光复，多省宣布独立。孙中山当时不在武昌，不能写成现场指挥者。
人物 / 角色
湖北新军中的革命力量：主要力量；文学社、共进会：组织准备；黎元洪：起义后被推为湖北军政府都督。
1911年12月下旬

孙中山回国，当选临时大总统

衔接武昌起义与南京临时政府成立。
人物 / 角色
孙中山：当选中华民国临时大总统。
1912年1月1日

中华民国临时政府成立

宣告中华民国成立。地点、日期、人物要一组记。
人物 / 角色
孙中山：在南京宣誓就任临时大总统。
1912年2月

清帝退位

清王朝统治结束，中国两千多年的君主专制制度终结；不等于整个封建制度已经结束。
人物 / 角色
清帝：退位；袁世凯：利用军政实力向清廷施压。
1912年3月

袁世凯就任临时大总统

袁世凯窃取辛亥革命果实，北洋军阀统治开始。注意区别后来“正式大总统”的身份。
人物 / 角色
袁世凯：在北京就任临时大总统；孙中山：此前辞去临时大总统职务。
1912年3月

《中华民国临时约法》颁布

主权在民，确立民主共和原则，意在约束权力。它是具有资产阶级共和国宪法性质的重要文件。
人物 / 角色
孙中山领导的南京临时政府：公布约法。
1912年

同盟会改组为国民党，尝试政党政治

为理解1913年宋教仁遇刺和二次革命提供背景。此条仅按年份记，不强行与同年各月事件排出先后。
人物 / 角色
宋教仁等：推动政党活动；革命派：试图通过议会政治维护共和。
05

专制复辟与维护共和1913—1917

二次革命、护国、护法，分别回应不同的政治危机。

专制复辟与维护共和 · 10 条记录（长期运动与具体节点可能重叠）
时间点 / 时段关键事件 · 结果与联系参与人物 · 具体角色
1913年

宋教仁遇刺

宋案成为二次革命的重要导火线。不要把“宋教仁—政党政治”与“宋案—反袁斗争”拆开记。
人物 / 角色
宋教仁：国民党重要人物，遭刺杀；袁世凯：其专制统治与革命派发生尖锐冲突。
1913年

二次革命

革命失败。直接针对袁世凯的专制与武力镇压，不是针对1915年才发生的称帝。
人物 / 角色
孙中山、黄兴等：领导革命派反对袁世凯；袁世凯：镇压革命力量。
1913年

袁世凯成为正式大总统、解散国民党

由临时大总统走向正式大总统，进一步破坏政党政治。
人物 / 角色
袁世凯：强迫国会选举其为正式大总统，随后下令解散国民党。
1914年

解散国会、废约法，扩大总统权力

修改总统选举法，规定总统可无限期连任、可指定继承人，为终身掌权铺路。
人物 / 角色
袁世凯：解散国会，废除《临时约法》，颁布《中华民国约法》，改内阁制为总统制。
1915年

接受日本“二十一条”中的大部分要求

不能简单写成原封不动接受全部“二十一条”。这与其谋求帝制相联系。
人物 / 角色
日本政府：提出侵略要求；袁世凯：以牺牲国家权益换取日本支持。
1915年底

袁世凯复辟帝制

将中华民国改为“中华帝国”，引起广泛反对。
人物 / 角色
袁世凯：宣布恢复帝制，拟以1916年为“洪宪元年”。
1915年底起

护国运动兴起

目标：反对袁世凯称帝，维护共和。1915年12月，云南宣布独立、起兵讨袁，护国战争爆发。
人物 / 角色
孙中山：号召反对帝制；蔡锷、唐继尧、李烈钧等：组织护国军事斗争。蔡锷任护国军第一军总司令。
1916年

袁世凯被迫取消帝制；随后去世

护国斗争取得反复辟胜利，但并未终结军阀统治。取消帝制与去世是先后两个节点。
人物 / 角色
袁世凯：在护国运动等压力下取消帝制，后去世。
1916年以后

军阀割据混战

共和国名义仍在，民主共和却缺乏稳定保障。不要把“袁世凯死后”误记成“国家立即统一”。
人物 / 角色
北洋军阀各派及地方军事势力：争权夺利；人民：承受战乱。
1917年起

护法运动

重点维护《临时约法》和国会，反对军阀专制；维护共和的努力遭遇挫折。
人物 / 角色
孙中山：领导维护共和的斗争；军阀势力：破坏民主共和。

最后，把三组易混点再过一遍

1894 与 1895

1894：兴中会、甲午战争爆发、黄海海战。1895：威海卫、《马关条约》、公车上书、广州起义。

1911 与 1912

1911：武昌起义。1912：中华民国成立、清帝退位、《临时约法》、袁世凯就任临时大总统。

1913 / 1915 / 1917

二次革命：反袁专制。护国：反对袁世凯称帝。护法：维护《临时约法》和国会。
