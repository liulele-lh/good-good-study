全等三角形：从重合到证明

先认识什么叫“全等”，再学会找到对应关系，最后尝试写出第一段几何证明。

什么是全等找对应关系怎样判定第一道证明自己试一试

1. 形状相同，大小也相同

把一个三角形剪下来，平移、旋转，必要时翻面。如果它能和另一个三角形完全重合，这两个三角形就叫全等三角形。

重合时，三个顶点、三条边和三个角，都能一一对上。移动、旋转或翻面不改变全等关系；放大或缩小通常会改变大小。

定义：能够完全重合的两个三角形叫作全等三角形。
△ABC ≌ △DEF
读作“三角形 ABC 全等于三角形 DEF”。

“看起来像”不能作为证明。两个三角形就算三个角分别相等，也可能一个大、一个小。

2. 写全等符号时，字母顺序有意义

上图重合后，A 对上 D，B 对上 E，C 对上 F。写成 △ABC ≌ △DEF，就是把对应顶点放在相同的位置。

对应对象一一对应全等后能得到
顶点A ↔ D，B ↔ E，C ↔ F按这个顺序配对
边AB ↔ DE，BC ↔ EF，AC ↔ DFAB = DE，BC = EF，AC = DF
角∠A ↔ ∠D，∠B ↔ ∠E，∠C ↔ ∠F对应角分别相等
性质：全等三角形的对应边相等，对应角相等。

顺序提醒：可以写 △BAC ≌ △EDF，因为两边同步调整了顺序。不能只随意调换一边的字母。

两个全等三角形的周长、面积也分别相等，但面积相等或周长相等，反过来都不能保证全等。

3. 不用剪下来，怎样判断全等？

画图能帮助理解，证明则需要依据已知条件。通常不必核对全部六组边角关系，满足下面一种判定就够了。S 表示边，A 表示角。

SSS：三边分别相等

若 AB = DE，BC = EF，AC = DF，则 △ABC ≌ △DEF。

图中两组三角形的边长均为3、4、5，对应三边分别相等。

三条边的长度确定后，三角形的形状和大小就确定了。好比三根固定长度的小棒围成一个三角形。

SAS：两边和它们的夹角分别相等

若 AB = DE，AC = DF，∠BAC = ∠EDF，则 △ABC ≌ △DEF。

一定要是“夹角”。AB 和 AC 的公共端点是 A，所以它们的夹角是 ∠BAC。不能把它换成 ∠B 或 ∠C。

ASA：两角和它们的夹边分别相等

若 ∠A = ∠D，∠B = ∠E，AB = DE，就能判定全等。

两个45°角分别在 A、B（D、E）处，蓝色的5单位长边正好连接这两个顶点，所以它是夹边。边固定后，两端射线的方向也固定，交点随之确定。

AAS：两角和一角的对边分别相等

若 ∠A = ∠D，∠B = ∠E，AC = DF，也能判定全等。

已知角仍然位于 A、B（D、E），但给定的是蓝色边 AC（DF），长4，它不是夹边，而是 ∠B（∠E）的对边。第三个角为180° − 45° − 45° = 90°，因此也能转化成 ASA。

各示例独立，边长单位相同；ASA 图与本图使用不同绘图比例，不比较两节图形的大小。

HL：直角三角形中的特殊判定

两个直角三角形，如果斜边和一条直角边分别相等，那么这两个直角三角形全等。H 表示斜边，L 表示直角边。

例如，∠C = ∠F = 90°，AB = DE（斜边），AC = DF（直角边），即可用 HL。

图中的小方框表示直角。与直角相对的蓝色斜边长5，另一条已知直角边长3。两组三角形能完全重合。

使用 HL，先确认两个都是直角三角形。斜边是直角所对的边，不能只看图上哪条边“斜着”。

两个容易误用的条件

条件能否保证全等原因
AAA：三个角分别相等不能形状一样，大小可以不同。例如边长3与边长6的两个等边三角形。
SSA：两边和其中一边的对角分别相等一般不能给定这些条件，可能出现两个不同的三角形。不能把 SSA 当成通用判定。

重点想一想：SAS 可以，SSA 为什么一般不可以？

假如两个三角形都有两条边长为5和4，长度4的边所对的角都是30°，它们一定全等吗？先想一想第三个顶点是否只有一个位置。

为什么不能？点击展开答案和反例图

不一定。下面两组三角形按相同比例绘制，两条已知边和一个非夹角分别相等，却明显不能完全重合。

已知条件△ABC△DEF
第一条边AC = 5DF = 5
第二条边BC = 4EF = 4
长度4的边所对的角∠A = 30°∠D = 30°
第三条边AB ≈ 1.21DE ≈ 7.45

两条已知边 AC 和 BC 的夹角在 C，不在 A。因此上面的30°不是夹角，不能套用 SAS。

为什么会出现两个不同形状？

把两种情况放在同一张图里：固定 A、C，点 B 要落在底边射线上，同时与 C 的距离为4。以 C 为圆心、4为半径的圆，会与这条射线相交于 B₁、B₂ 两点。

所以 △AB₁C 和 △AB₂C 满足相同的 SSA 条件，但 AB₁ ≠ AB₂，第三边不同，两个三角形不全等。

反例的作用：只要找到一组“条件都相同、三角形却不全等”的例子，就说明 SSA 不能作为一般判定。

上图边长按比例绘制，第三边的小数仅帮助比较，不要求现在计算。SSA 并非在任何附加条件下都无效；直角三角形的 HL 就有额外的直角条件。

判定方法之间，也可以相互转化

AAS 和 ASA 可以互相转化。关键不是改变题目条件，而是利用“三角形内角和为180°”，补出第三组相等的角，再重新选择所用的两组角。

若 ∠A = ∠D，∠B = ∠E，那么：
∠C = 180° − ∠A − ∠B
∠F = 180° − ∠D − ∠E
所以 ∠C = ∠F。这一步只用了内角和定理，还没有假设三角形全等。

AAS → ASA：换成已知边两端的角

已知 ∠A = ∠D，∠B = ∠E，AC = DF。AC 不是 ∠A、∠B 的夹边，原来是 AAS。

① 由内角和，求出 ∠C = ∠F。

② 改用 ∠A = ∠D、∠C = ∠F，以及 AC = DF。

③ AC 正好夹在 ∠A、∠C 之间，DF 正好夹在 ∠D、∠F 之间，因此可以使用 ASA。

ASA → AAS：换用另一组角

已知 ∠A = ∠D，∠B = ∠E，AB = DE。AB 是 ∠A、∠B 的夹边，原来是 ASA。

① 由内角和，求出 ∠C = ∠F。

② 改用 ∠A = ∠D、∠C = ∠F，以及 AB = DE。

③ AB 是 ∠C 的对边，DE 是 ∠F 的对边，不是所选两角的夹边，因此可以使用 AAS。

统一理解：两组对应角分别相等，再有一组对应边相等，就能确定两个三角形全等。
边没有换，只是所选的两组角改变了，“夹边”或“对边”的说法也随之改变。

其他判定也能这样转吗？

关系需要的依据能得到什么
AAS ↔ ASA三角形内角和为180°两组角相等，可以补出第三组角相等。
HL → SSS勾股定理，以及两者都是直角三角形斜边和一条直角边分别相等，另一条直角边也相等。
SSA 不能直接变成 SAS缺少能确定夹角相等的条件非夹角相等，不保证夹角相等；前面的反例就有两种形状。
AAA 不能补成全等判定缺少边长信息三个角确定形状，但不能确定大小。

为什么 HL 可以？已知两条边，还能发现什么相等？

回到 HL 图：∠C = ∠F = 90°，斜边 AB = DE = 5，直角边 AC = DF = 3。看起来只有两组边相等，为什么就能保证全等？

直角这个条件还藏着更多信息。先分别想想下面两个问题，再点击按钮展开解释。

思路一：另一条直角边还能自由变化吗？
如果斜边和一条直角边都固定了，剩下的第三条边是不是也就确定了？

由勾股定理，补出第三组相等的边

两图使用相同比例。蓝色直角边与红色斜边是已知条件；绿色第三边由勾股定理求出。

在两个直角三角形中：

BC² = AB² − AC² = 5² − 3² = 16
EF² = DE² − DF² = 5² − 3² = 16。

因为边长为正，所以 BC = EF = 4。

现在三组对应边都相等：

AB = DE，AC = DF，BC = EF。

因此 △ABC ≌ △DEF（SSS）。

一般地，设斜边都为 c，一条直角边都为 a，另外两条直角边为 b₁、b₂，则 b₁² = c² − a² = b₂²。两条边长为正，所以 b₁ = b₂。

HL → 勾股定理 → 第三边也相等 → SSS。

还没学过勾股定理，可以先记住：直角三角形的斜边和一条直角边确定后，另一条直角边也随之确定。

思路二：除了边，还能推出哪个角相等？
两个直角三角形中，“一条直角边 ÷ 斜边”的比值相同。这能不能帮助我们找到一组相等的锐角？

由正弦值，补出一组相等的锐角

选取右下角的 ∠B、∠E：蓝色边是它们的对边，红色边是斜边。绿色弧线标出要研究的锐角，角相等由下面的正弦关系推出。

直角三角形中，一个锐角的正弦值 = 对边 ÷ 斜边。本图的已知直角边 AC、DF，分别是 ∠B、∠E 的对边，所以选择这两个角：

sin B = AC / AB = 3/5
sin E = DF / DE = 3/5。

因此 sin B = sin E。

∠B 和 ∠E 都是锐角。在 0° 到 90° 的锐角范围内，角越大，正弦值越大；相同的正弦值对应同一个锐角。因此 ∠B = ∠E。

“正弦值相等”并不是在任意角度范围内都能推出角相等。这里能够推出，是因为已经知道两个角都是锐角。

接下来，可以用 AAS，也可以转为 ASA

方法一：AAS。
∠B = ∠E，∠C = ∠F = 90°，AB = DE。斜边 AB、DE 是这两个直角的对边，不是所选两角的夹边。由 AAS，△ABC ≌ △DEF。

方法二：ASA。
由内角和，∠A = 90° − ∠B，∠D = 90° − ∠E，因此 ∠A = ∠D。改用 ∠A = ∠D、∠B = ∠E 和它们的夹边 AB = DE，由 ASA 得到全等。

HL → 对边与斜边的比值相同 → 对应锐角的正弦值相同 → 对应锐角相等 → AAS 或 ASA。

这是学过锐角三角函数后的回看解释，入门时不必掌握。具体课程中各定理的证明有先后顺序；如果正弦比值的定义与性质已经依赖全等或相似，这条路线应作为知识联系来理解，而不能未经核查就当作 HL 的独立基础证明。

避免绕圈证明：可以先用内角和等已知定理补条件，再证明全等；不能先说“因为全等，所以第三组角相等”，再拿这组角去证明全等。

4. 跟着写第一道证明

已知：如图，AB = AD，BC = DC，连接 AC。
求证：∠BAC = ∠DAC。

想证明两角相等，可以先找它们所在的两个三角形：△ABC 和 △ADC。除了题目给出的两组等边，还有一条容易忽略的条件：AC 是它们共同的一条边。

在 △ABC 和 △ADC 中：

AB = AD　（已知）
BC = DC　（已知）
AC = AC　（公共边）

所以 △ABC ≌ △ADC（SSS）。

所以 ∠BAC = ∠DAC（全等三角形的对应角相等）。

证明的顺序：找三角形 → 找三组条件 → 判定全等 → 得到目标边或角相等。

这道题中，∠BAC = ∠DAC 是待证明的结论，不能一开始就把它当作已知条件。

除了题目给的条件，还能找什么？

  • 两个三角形共用的边或角。
  • 对顶角相等。
  • 平行线产生的内错角或同位角相等。
  • 线段中点产生两条相等的线段，角平分线产生两个相等的角。

这些都要有题目条件或已学定理支持，不能只凭图画得像。

5. 自己试一试

先独立判断，再展开答案。每题都说出理由，比只写“能”或“不能”更重要。

第1题 · 找对应边

已知 △ABC ≌ △FDE。AB 对应哪条边？∠C 对应哪个角？若 BC = 7，哪条边也等于7？

做完了，看看答案对不对吧

按顺序：A ↔ F，B ↔ D，C ↔ E。所以 AB 对应 FD；∠C 对应 ∠E；DE = BC = 7。

第2题 · 夹角到底在哪里？

在 △ABC 和 △DEF 中，AB = DE，AC = DF。再加上哪一个条件，就可以使用 SAS？

① ∠B = ∠E　　② ∠A = ∠D

做完了，看看答案对不对吧

选②。AB、AC 的夹角是 ∠A，DE、DF 的夹角是 ∠D。选①时不是两条已知边的夹角，不能直接使用 SAS。

第3题 · ASA 还是 AAS？

已知 ∠A = ∠D，∠C = ∠F，AB = DE。能否判定 △ABC ≌ △DEF？使用什么方法？

做完了，看看答案对不对吧

能，使用 AAS。两组已知角的夹边是 AC 和 DF；题目给的是 AB 和 DE，它们分别是 ∠C 和 ∠F 的对边。

第4题 · 三个角都相等，够不够？

两个三角形的三个角都分别是60°，可以判定它们全等吗？请给出理由或反例。

做完了，看看答案对不对吧

不能。边长2的等边三角形和边长5的等边三角形，三个角都是60°，但大小不同。

第5题 · 认清斜边

在 △ABC 和 △DEF 中，∠B = ∠E = 90°，AC = DF，AB = DE。可以使用哪种判定？

做完了，看看答案对不对吧

HL。AC、DF 分别是直角 ∠B、∠E 的对边，因此是斜边；AB、DE 是一组对应直角边。

第6题 · 从全等走向结论

回到第4节的图。已知 AB = AD，BC = DC，请证明 ∠BCA = ∠DCA。写出三组条件及判定方法。

做完了，看看答案对不对吧

在 △ABC 和 △ADC 中，AB = AD，BC = DC（已知），AC = AC（公共边）。

所以 △ABC ≌ △ADC（SSS）。

所以 ∠BCA = ∠DCA（全等三角形的对应角相等）。

6. 今天先记住这四句话

  1. 全等是形状相同，大小相同，能够完全重合。
  2. 写全等关系时，对应顶点按顺序写。
  3. 判定全等要找条件：SSS、SAS、ASA、AAS；直角三角形还可用 HL。
  4. 先用条件证明全等，再用性质得到对应边、对应角相等。

暂时记不住字母也没关系。先能说清楚“三条边”“两边及夹角”“两角及一边”，再把它们与符号对应起来。

学习建议：先操作重合图，再跟写第4节的证明，最后独立完成练习。打印前展开想保留的答案即可。
