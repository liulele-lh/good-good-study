整数计数建模
双端点计入练习

第二篇 · 连续整数表示、边界定位与分类讨论

1. 知识点总结

这个方法有专门的名字吗？

这里用的是几种常见思路的组合，并不是一个需要背诵的专名定理。可以把它概括为“区间整数计数的边界建模”，这是便于理解的描述性名称。

  • 连续整数表示：恰好两个整数就设为 k、k + 1；恰好 N 个整数就设为 k、k + 1、…、k + N − 1。
  • 边界定位：既包含目标整数，又排除左右相邻的整数，把个数要求转化为不等式组。
  • 分类讨论：找出整数 k 的可能值，分别求 x 的范围，再取并集。

从整体上看，这是转化思想：把“有几个整数”的计数问题转化为“边界落在哪里”的不等式问题。结合图像理解时，也用到了数形结合。

k 表示什么？

k 是区间内最小的整数，并不是函数的斜率。x 仍然可以取实数。确定 k，等于确定了要包含哪一组整数。

为什么整数一定连续？

一个区间若包含两个整数，也一定包含它们之间的所有整数。因此，“恰好两个整数”不能是 1 和 3，因为这样还会包含 2；只能写成 k、k + 1。

端点计入规则决定等号的位置

设下边界为 L，上边界为 U，目标是恰好包含 k、k + 1：

区间规则下边界条件上边界条件
上一篇：(L, U]k − 1 ≤ L < kk + 1 ≤ U < k + 2
本篇：[L, U]k − 1 < L ≤ kk + 1 ≤ U < k + 2

本篇下端也计入：L 可以等于 k，但不能等于 k − 1，否则会多包含一个整数。

求公共范围时，端点碰到一起也要检查。两个区间即使只共用一个点，只要双方都包含这个点，交集仍然非空。例如 (−1, 0] 与 [0, ½) 的交集为 {0}。

因此，同一个 k 下取交集，不同 k 的结果取并集；不能直接照搬上一篇所有严格不等号。

2. 新题目：两个端点都计入

已知两个一次函数：

y₁ = x

y₂ = 2x + 1

要求第二个函数值大于第一个函数值。求所有实数 x，使满足下面不等式的整数 n 恰好有两个：

x ≤ n ≤ 2x + 1。
注意：两个端点都计入。整数若恰好等于 x 或 2x + 1，都要计入。研究的是闭区间 [x, 2x + 1]。

请写出建模过程、k 的可能值及对应的 x 范围，并检查所有端点。答案可能含有孤立的一个数。

3. 答案与解析

第一步：确定上下关系

2x + 1 > x ⇒ x > −1。

第二步：表示两个整数，定位边界

设恰好包含的两个整数为 k、k + 1，k 为整数。为了排除 k − 1 和 k + 2，同时包含 k 与 k + 1，需要：

k − 1 < x ≤ k
k + 1 ≤ 2x + 1 < k + 2。

第二条整理为：

k/2 ≤ x < (k + 1)/2。

第三步：确定整数 k

求区间 (k − 1, k] 与 [k/2, (k + 1)/2) 的公共部分：

k − 1 < (k + 1)/2 ⇒ k < 3
k/2 ≤ k ⇒ k ≥ 0。

第二条可以取等号。因为第一个区间的右端 k 和第二个区间的左端 k/2 都包含在各自区间中，相等时这个点仍可能是解。

所以 0 ≤ k < 3，整数 k 可取 0、1、2。

第四步：逐个代入，取交集

k第一个范围第二个范围公共部分两个整数
0−1 < x ≤ 00 ≤ x < ½x = 00、1
10 < x ≤ 1½ ≤ x < 1½ ≤ x < 11、2
21 < x ≤ 21 ≤ x < 3/21 < x < 3/22、3

三种情况均满足 x > −1。合并得：

最终答案
x ∈ {0} ∪ [½, 1) ∪ (1, 3/2)

也就是 x = 0，或 ½ ≤ x < 1，或 1 < x < 3/2。

第五步：检查端点和孤立点

x闭区间 [x, 2x + 1]包含的整数结论
0[0, 1]0、1符合，两端均计入
½[½, 2]1、2符合
1[1, 3]1、2、3不符合，必须排除
3/2[3/2, 4]2、3、4不符合，必须排除

在 x = 0 附近，−½ < x < 0 时区间中只有整数 0；0 < x < ½ 时区间中只有整数 1。只有 x = 0 时，两个端点 0 和 1 同时被计入，所以出现孤立解 {0}。

本题最容易漏掉的是 x = 0，最容易多算的是 x = 1。这两点都提醒我们：端点是否包含，是建模条件的一部分。
