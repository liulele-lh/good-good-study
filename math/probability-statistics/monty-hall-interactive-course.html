三门问题：为什么换门更有利？

从完整题目出发，先作判断，再把每一步的理由讲清楚。

01 / 先读题

两只羊，一辆汽车，你会怎么选？

你参加一档抽奖节目，面前有1号、2号、3号三扇关闭的门。其中一扇门后有汽车，另外两扇门后各有一只羊。汽车等可能地放在任意一扇门后。选中汽车，就能赢得汽车。

  1. 你先选一扇门，但不打开。为方便讨论，假设你选1号门。
  2. 主持人知道汽车的位置。他一定从你没选的两扇门中，打开一扇有羊的门。如果两扇都是羊，他就随机打开其中一扇，各占一半。
  3. 主持人一定给你换门的机会。你可以坚持1号门，也可以换到另一扇未打开的门。
🚪1号门你最初选的门
🚪2号门另一扇未打开的门
🐐3号门假设主持人打开它

为了尽可能赢得汽车，哪种做法更有利？

先选你的判断，随后揭晓答案并开始讲解。这里选择的是解题判断。

02 / 揭晓答案

应该换门，中奖概率是原来的两倍。

坚持原门1/3约33.3%
换到另一扇门2/3约66.7%

这不是说换门一定赢，而是说：如果按这个规则反复玩，采用换门策略更容易中奖。下面先不用复杂公式。

03 / 最关键的一步

换门能不能赢，只看最初选对还是选错。

如果最初选中了汽车

另外两扇门后都是羊。主持人打开一扇羊门，剩下的另一扇仍是羊。这时不换赢，换门输。最初选中汽车的概率是1/3。

如果最初选中了一只羊

另外两扇门后面必然是一辆汽车、一只羊。主持人必须打开羊门，于是剩下的另一扇门后一定是汽车。这时不换输，换门赢。最初选中羊的概率是2/3。

换门赢 ⇔ 最初选错。
最初选错的概率是2/3，所以换门赢的概率也是2/3。
04 / 把所有情况列出来

三种等可能的汽车位置，两种换门会赢。

仍然假设你最初选1号门。下面比较完整游戏中的两种策略，暂时不限定主持人一定开3号门。

汽车位置概率主持人开门不换换门
1号门1/32或3号羊门赢输
2号门1/33号羊门输赢
3号门1/32号羊门输赢

第一行虽然有两种开门方式，但无论主持人开哪扇，换门都会输。因此不必把它拆开，直接按三种等可能的汽车位置计数即可。

P（换门赢）= 2种有利情况 ÷ 3种等可能情况 = 2/3
05 / 解决最常见的疑惑

只剩两扇门，为什么不是各占一半？

只有两个可能结果，不代表两个结果等可能。比如一次罚球只有“进”和“不进”，也不能因此断定命中概率是1/2。

在三门问题里，主持人知道答案，并按规则排除羊门。他保证了：只要你最初选错，另一扇留下的门就是汽车。你最初选错本来就更有可能，概率是2/3。

注意题目的条件：主持人一定开羊门，一定让你换门。他不是随便开一扇门、恰好看到羊。
06 / 专门解释“打开3号门后”的概率

用600局，看看信息怎样筛选可能性。

现在回到开头的具体画面：你选1号门，并且看到主持人打开了3号门。为什么此时汽车在1号门的概率为1/3，在2号门为2/3？

想象进行了600局，每次都先选1号门。按理论比例，汽车在三个位置的情况各约200局。我们只保留“主持人打开3号门”的局：

汽车在1号门

约200局。主持人在2、3号羊门中任选，只有一半开3号门。

留下约100局
汽车在2号门

约200局。1号门是你选的，2号门有车，只能开3号门。

留下约200局
汽车在3号门

约200局。主持人不能打开汽车门，因此绝不会开3号门。

留下0局
汽车位置筛选前留下的局数占留下局数的比例
1号门约200局约100局100 ÷ 300 = 1/3
2号门约200局约200局200 ÷ 300 = 2/3
3号门约200局0局0

分母为什么变成300？因为已经知道“主持人开了3号门”，我们就只在符合这个条件的约300局中讨论汽车位置，其余局不再计入。

为什么留下的100和200不一样多？因为汽车在1号门时只有一半机会开3号门；汽车在2号门时一定开3号门。这个信息对两种情况的筛选力度不同。

600局是帮助理解理论比例的假想例子。实际随机进行600局，局数会有波动，不保证恰好是这些数。这里用到了“两扇羊门可选时，主持人各以一半概率打开”的规则。

07 / 联系独立与不独立

不独立，也可以是“获得信息后，概率变了”。

假设你选1号门，定义两个事件：

  • A：汽车在2号门。
  • B：主持人打开3号门。

不知道汽车位置时，主持人打开3号门的概率是1/2；但如果知道汽车在2号门，主持人就一定打开3号门，概率变成1。知道A发生，会改变B的概率，所以A、B不独立。

也可以反过来看：知道主持人开了3号门后，汽车在2号门的概率从1/3变为2/3。这叫在已知条件下计算概率，也就是条件概率。

汽车的位置没有改变，改变的是我们掌握的信息。不独立不一定意味着“前一件事把后一件事改变了”。
08 / 用一句话检查理解

换门在哪种情况下必定能赢？

记住这条完整的理由：

最初选错的概率是2/3 → 主持人必须排除羊门 → 最初选错时换门一定赢 → 换门中奖概率是2/3。

概率 · 三门问题的下一步

变成四扇门，换门还有利吗？

从题目到理由，分别讲清楚“打开两扇羊门”和“只打开一扇羊门”。

01 / 先把规则说完整

四扇门，三只羊，一辆汽车。

你参加抽奖节目，面前有1、2、3、4号四扇关闭的门。一扇门后有汽车，另外三扇门后各有一只羊。汽车等可能地放在任意一扇门后。你先选一扇，暂时不打开。为方便讨论，假设你选了1号门。

主持人知道汽车的位置。他一定只打开你没有选中的羊门，并且一定给你换门的机会。如果有多种符合规则的开门选法，他在这些选法中等可能地随机选择。

四门问题还必须补充一个条件：主持人打开几扇羊门？
打开两扇：只剩你的门和另一扇门。
只开一扇：还剩你的门和另外两扇门。

我们先分析第一种，再分析第二种。每种情况都只作一次最终选择。

02 / 情况一：打开两扇羊门

只剩两扇门，你认为换门的中奖概率是多少？

例如，你选1号门，主持人打开3号、4号两扇羊门。现在可以坚持1号门，或换到2号门。

🚪1号门你最初选的门
🚪2号门可以换过去
🐐3号门主持人打开
🐐4号门主持人打开

先选判断，随后弹出答案并展开解释。

03 / 先抓住核心

打开两扇羊门：换门中奖概率是3/4。

坚持原门1/425%
换到唯一另一扇门3/475%

最初选中汽车：概率1/4

另外三扇门都是羊。主持人打开其中两扇，剩下的一扇仍然是羊。换门输，不换赢。

最初选中羊：概率3/4

另外三扇门后有一辆汽车、两只羊。主持人必须打开两扇羊门，剩下的那扇门就一定是汽车。换门赢，不换输。

换门赢 ⇔ 最初选错。
最初选错的概率是3/4，所以换门中奖概率是3/4。
04 / 列举验证

四种等可能的位置，三种换门会赢。

下面考察所有完整游戏，不限定主持人具体打开哪两扇门。你一直先选1号门。

汽车位置概率主持人打开换门结果
1号门1/42、3、4号中任意两扇换到羊，输
2号门1/43号和4号换到2号门，赢
3号门1/42号和4号换到3号门，赢
4号门1/42号和3号换到4号门，赢
P（换门赢）= 3 ÷ 4 = 3/4

这与三门问题的结构相同：三门时最初选错的概率是2/3；四门时是3/4。只要主持人把其他羊门全部排除，换门就能在你最初选错时获胜。

05 / 为什么剩两扇门，也不是各一半？

用1200局，解释看到“3号、4号都是羊”之后的概率。

想象1200局都先选1号门。按理论比例，汽车在每个位置各约300局。现在只保留“主持人打开3号和4号”的局，不区分这两扇门打开的先后顺序。

车在1号

可开{2,3}、{2,4}、{3,4}，三种选法等可能。只有1/3符合。

留下约100局
车在2号

必须打开3号和4号，全部符合。

留下约300局
车在3号

绝不能打开3号汽车门。

留下0局
车在4号

绝不能打开4号汽车门。

留下0局

留下的约400局中：

  • 汽车在1号门：100 ÷ 400 = 1/4。
  • 汽车在2号门：300 ÷ 400 = 3/4。

分母变成400，是因为已经知道主持人打开了3、4号门，只讨论符合这个条件的局。两种汽车位置留下来的局数不同，所以不是一半一半。

这里是理论比例对应的假想局数，实际1200局会有随机波动。这个按具体门号筛选的计算，使用了主持人在所有合法开门选法中等可能选择的规则。

06 / 情况二：只打开一扇羊门

还有两扇门可以换，答案会改变吗？

重新开始讨论另一套规则：你仍先选1号门，但主持人只打开一扇羊门。例如，他打开4号门后，1、2、3号门仍关闭。

你可以坚持1号门，也可以在另外两扇未打开的门中，各以一半概率随机选一扇换过去。选定后立即揭晓，主持人不再继续开门。

这次“换门”不再是换到唯一剩下的门，而是从两个候选门中随机选一个。

按这种随机换门策略，中奖概率是多少？

07 / 分两步相乘

只打开一扇：随机换门中奖概率是3/8。

第一步：你最初必须选错。

如果最初选中汽车，换到哪里都是羊。因此换门要赢，首先要最初选中羊，这个概率是3/4。

第二步：在最初选错的条件下，还要从两扇门中选中汽车。

最初选中羊时，另外三扇门后是“一辆汽车、两只羊”。主持人只排除一只羊，还剩一辆汽车、一只羊。从这两扇门中随机选一扇，有1/2的机会选到汽车。

P（随机换门赢）= 3/4 × 1/2 = 3/8
这里的1/2是“在最初已经选错的条件下”，换门选中汽车的概率。不是整个问题的最终中奖概率。

这正是概率乘法的用法：先算进入有利情况的概率，再乘以在这个条件下下一步成功的概率。

坚持原门1/425%
随机换到一扇其他门3/837.5%

随机换门依然比不换更有利，但3/8还不到一半。“比原来更容易赢”，不代表“一定超过一半”。

08 / 再用具体门号验证

看到主持人打开4号门后，三个位置的概率是多少？

仍用1200局，每个汽车位置各约300局。这次主持人只开一扇羊门，并在合法羊门中等可能选择。只保留“打开4号门”的局：

汽车位置主持人开4号门的概率留下的局数在留下局数中占比
1号门1/3（在2、3、4中选）约100100/400 = 1/4
2号门1/2（在3、4中选）约150150/400 = 3/8
3号门1/2（在2、4中选）约150150/400 = 3/8
4号门0（不能打开汽车门）00

所以1、2、3号门并非各有1/3概率。原来的1号门占1/4，另两扇门各占3/8。两扇候选门合计3/4，但你最终只能选择其中一扇。

随机选2号门或3号门的中奖概率是：1/2 × 3/8 + 1/2 × 3/8 = 3/8，和前面按步骤算的结果一致。

实际局数可能波动。这张表按具体门号计算，也依赖主持人等可能选择合法羊门的规则。

09 / 放在一起比较

真正影响结果的是：主持人排除了多少扇羊门。

规则不换门换门最初选错后
三门，开一扇羊门1/32/3换门一定赢
四门，开两扇羊门1/43/4换门一定赢
四门，只开一扇羊门1/43/8（随机换）随机换门只有一半机会赢

前两种可以直接用“换门赢等于最初选错”来计数。第三种还需要在最初选错之后再选一次，因此多乘一个1/2。

与“不独立”的联系

主持人能开哪扇门，受到汽车位置的限制。例如你选1号门时，如果汽车在4号门，主持人就绝不可能打开4号门。开门行为会提供信息，不能把剩下的门直接当成等可能结果。

10 / 检查理解

只打开一扇羊门时，为什么不能直接说换门赢的概率是3/4？

记住两条推理：

开两扇羊门：最初选错 → 换门必胜 → 概率3/4。
只开一扇羊门：最初选错 → 随机换门有一半机会赢 → 概率3/4 × 1/2 = 3/8。
