把每个现象拆成可判断的步骤

不靠关键词猜答案：先确定研究对象和初末状态，再结合吸放热、图像和实验条件逐段判断。

统一现象题方法统一图像题方法分析实验与连续变化

现象题四步法

  1. 找研究对象
  2. 确定初态
  3. 确定末态
  4. 根据状态变化判断名称和吸放热
例：空气中的水蒸气 → 小水滴；气态 → 液态；液化，放热。

图像题七步法

  1. 看横轴、纵轴和单位
  2. 判断升温还是降温
  3. 找恒温平台
  4. 判断吸热还是放热
  5. 判断物态及是否为晶体
  6. 读取熔点、凝固点或沸点
  7. 逐段写出各时间段状态

图像综合辨析

平台段不表示“没有能量变化”。晶体仍在吸热，固态部分减少、液态部分增加；微粒平均动能近似不变，所以温度不变。

熔化实验检查表

  • 水浴加热：均匀、缓慢
  • 温度计玻璃泡接触被测物，不碰容器
  • 固定时间间隔记录温度和状态
  • 横轴写时间，纵轴写温度并注明单位
  • 多次取样寻找普遍规律

沸腾实验检查表

  • 器材一般自下而上安装
  • 温度计不碰杯底、杯壁
  • 适当加盖但绝不能密闭
  • 沸腾前气泡由大变小，沸腾时由小变大
  • 减少水量、提高初温可缩短加热时间

控制变量与误差

控制变量：研究蒸发快慢时，一次只改变温度、表面积或风速中的一个。
加热时间：使用同一加热器且效率相近时，可近似反映吸收热量多少，不等同于温度。
多次实验：取平均值可减小测量误差；改变条件多次实验可寻找普遍规律。

连续变化：必须逐段判断

冰 → 水 → 水蒸气 → 小水滴 → 霜
过程变化能量
冰 → 水熔化吸热
水 → 水蒸气汽化吸热
水蒸气 → 小水滴液化放热
水蒸气 → 霜凝华放热
若题目写“小水滴 → 霜”，还要结合过程判断是否先凝固，不能直接把液态跳成固态称为凝华。
