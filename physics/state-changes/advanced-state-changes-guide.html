01 / 微观本质不是所有变化都叫“挣脱束缚”

冰、液态水、水蒸气中的分子都是 H₂O。物态变化改变的是大量分子的排列、间距、运动方式与相互作用状态，不是把水分子拆成氢和氧。固态、液态、气态是集体状态，不是三种不同的水分子。

变化微观理解通常的吸放热
熔化：冰 → 水冰的有序结构被破坏，分子能够相对移动；液体中仍有分子间吸引。吸热
汽化：水 → 水蒸气分子脱离液体进入气相，分子间距通常大幅增大。吸热
升华：冰 → 水蒸气分子直接脱离冰，进入气相，不必经过液态。吸热
凝固、液化、凝华分别是上述三个过程的反向变化，分子进入相应的结合或有序状态。放热
“挣脱分子间吸引”有助于理解汽化、升华；但熔化不是分子间作用力全部消失，凝华更不是挣脱束缚。

熔点和沸点也不是温度的极限：冰全部形成后可以继续降温，水全部汽化后也可以继续升温。吸热不一定升温，放热也不一定降温。

02 / 两种汽化方式能蒸发，为什么还要等到沸点？

蒸发 · 从表面离开

同一温度下，分子的能量并不相同。部分表面分子有足够能量脱离液体，因此室温下就能蒸发。

气相分子也会返回液体。只有离开的多于返回的，水量才会净减少。

沸腾 · 内部蒸气泡长大

液体内部的气泡受到周围压力。如果泡内蒸气压力不足，蒸气泡就难以持续长大。

升温提高饱和蒸气压，达到相应条件后，液体内部也能持续汽化。

沸点：饱和蒸气压 ≈ 外界压力时的温度

上式采用常见教材近似，忽略液体深度、气泡曲率及成核造成的影响；实际也可能发生过热。加热初期的小气泡还可能来自溶解空气，不能见到气泡就断定已沸腾。

沸点不是分子第一次能逃出去的温度。 外界压力降低，沸点降低；外界压力升高，沸点升高。

熔化为什么有熔点？

在一定压力下，低于熔点，冰是更稳定的平衡相；高于熔点，水是更稳定的平衡相；在熔点，冰和水可以平衡共存。它是固体与液体两种集体结构的平衡条件，不是所有分子突然同时获得相同能量。

纯冰在压力不变、接近平衡的熔化过程中继续吸热，改变的是冰水比例，温度不变。实际相变可能因成核等因素延迟，例如过冷水。

03 / 最重要的两个量实际分压 ≠ 饱和蒸气压

实际水蒸气分压 p

周围气体中，水蒸气实际贡献的那部分压力。气态水分子的数量、所占空间和温度都会影响它。

冰面饱和蒸气压 pₛ(T)

在给定冰面温度下，冰与水蒸气平衡时的蒸气压。普通条件下主要由冰面温度决定：温度越低，饱和值通常越低。

以下比较针对已有的冰面，采用普通压力、近似平坦界面等条件。冰面既有升华，也有凝华；比较两个方向的速率，才知道冰在宏观上增多还是减少。

实际分压与饱和值微观交换宏观结果
p < pₛ(T)升华快于凝华净升华，冰减少
p = pₛ(T)升华与凝华一样快动态平衡，冰的量无净变化
p > pₛ(T)凝华快于升华净凝华，冰增长

切换环境，看“净变化”方向

定性示意：保持冰面温度不变，只改变周围实际水蒸气分压。箭头表示相反的交换过程，不代表精确速率。

动态平衡：不是没有变化，而是进出相抵。

水分子仍在升华，也仍在凝华。宏观上冰的量不再净改变。

饱和不是“禁止分子逃离”的开关。 低于、等于、高于饱和值，都可能存在双向交换；只有相等时，才是相平衡。

凝华之后，下降的是哪一个压力？

在温度、容积固定的密闭容器中，水蒸气净凝华后，气态水分子减少，下降的是实际分压。冰面温度不变，饱和值就基本不变。实际分压趋向饱和值后，净凝华停止，但双向交换继续。

反过来，未饱和时冰净升华，实际分压会上升；冰足够多、时间足够长，就可能达到平衡。若一直抽走蒸气，则不一定能达到平衡。

这就是它的“温度条件”：温度决定平衡标准，实际分压与标准的比较决定净变化方向。 对液态水，换用水面温度对应的液态水饱和蒸气压，比较蒸发与凝结。冰面和液态水面的饱和值不能混用；最初形成冰晶还涉及成核条件。

04 / 把条件画成地图纯水相图，到底告诉我们什么？

横轴是温度，纵轴是压力。它描述的是纯水在平衡条件下的稳定物态，不是“任何瞬间都必须如此”的过程录像。纯水不要求真空：冰、水、水蒸气都属于同一种物质。

位置物理含义
区域内部在给定温度、压力下，稳定的平衡相是该区域标注的物态。
AB：固—气线冰和水蒸气平衡共存，对应升华／凝华的平衡条件。
BD：固—液线冰和水平衡共存，对应熔化／凝固的平衡条件。负斜率表示在此范围内加压会降低熔点。
BC：液—气线水和水蒸气平衡共存，也给出饱和蒸气压随温度的关系。
B：三相点约 0.01℃、0.611 kPa，冰、水、水蒸气能平衡共存。
C：临界点约 374℃、22.1 MPa，是液—气平衡线的终点。到这里两相区别消失；温度、压力都高于临界值时为超临界流体。
固定一个适当压力，水平线与某条相界线的交点给出两相的平衡温度。这也适用于升华／凝华，并不是只有熔化、沸腾才有温度—压力条件。

一个点，不等于“变化刚好完成”

同一个两相平衡点，可以是“较多水＋较少水蒸气”，也可以相反。相图没有给出质量、体积和比例。持续汽化时，坐标可以不动，而气相比例不断增大。

液态区是不是说“只剩液态”？

准确说，是稳定的平衡相只有液态。单个 H₂O 分子没有“液体分子”“气体分子”之分。若系统刚被扰动、还没达到平衡，可能暂时存在气泡等现象；不能因此认为相图矛盾。

05 / 一杯水为什么不受“液态区”限制？纯水系统与空气中的水

空气总压强 ≠ 水蒸气分压

室内一个大气压，主要由氮气、氧气等贡献。水蒸气只是其中一部分。杯中水能否净蒸发，要比较周围实际水蒸气分压与水面温度对应的饱和值。

只有纯水

20℃、约 101 kPa，稳定平衡相是液态；20℃ 的液—气共存压力则约为 2.34 kPa。

水＋空气

即使总压力为约 101 kPa，只要水蒸气未饱和，水仍可净蒸发。饱和且与水同温时，可达到动态平衡。

不能把空气总压力直接放进纯水相图，来判断杯中的水是否蒸发。 混合物需要增加组成信息；但这并不意味着有空气后，所有相变就失去了条件。

蒸发冷却：不是因为“分子少了”

蒸发带走能量，若环境补充不足，剩余水的平均热运动能量降低，水温下降。倒掉半杯水也减少分子数，却不会因此必然降温。水冷却后，较暖的环境可以向它传热；供热与损失相抵时，水可以在较低的稳定温度下继续蒸发。

06 / 20℃ 的活塞实验“制造一个空腔”在图上怎么走？

设想一个只有纯水、没有空气的活塞容器。保持 20℃，缓慢向外拉活塞，并允许系统接近平衡。忽略重力造成的压差和细小界面的影响。

  1. 起点：约 101 kPa，全部是液态，坐标在液态区。
  2. 容积略增：液态水略微膨胀，压力下降，坐标沿 20℃ 竖线向下移动。
  3. 到达约 2.34 kPa：到达液—气分界线，可以形成稳定的两相共存。
  4. 继续增容：部分水汽化填充空间，气相比例增加；只要两相都在，温度、压力可以暂时都不变。需要外界供热维持 20℃。
  5. 全部汽化：继续恒温增容，蒸气压力下降，坐标进入气态区。
突然造出空洞，是另一种过程。 空洞内与周围液体可能压力不同，不能用一个统一的平衡坐标描述。若周围水仍为 20℃、一个大气压，纯水蒸气空洞不能稳定平衡共存，会倾向于塌缩。真实形成气泡还受成核与表面张力影响。

07 / 固定什么，路径就不同加热不一定出现“恒温平台”

共同起点：纯水与水蒸气在 20℃、约 2.34 kPa 平衡共存。下面分别改变操作条件。

控制条件两相共存时相图中的表现
恒压加热，允许膨胀温度约 20℃，气相比例增加。全部汽化后再加热，蒸气可升温。先停在同一点，全部汽化后水平向右。
恒温缓慢增容压力约 2.34 kPa，气相比例增加。全部汽化后再增容，压力下降。先停在同一点，全部汽化后竖直向下。
密闭、定容加热在仍有两相且接近平衡时，温度、压力共同升高，相比例改变。沿液—气分界线向右上方移动。

选择控制方式

温度不变 · 压力不变 · 蒸气比例增加

在约 2.34 kPa 下持续供热，容器允许膨胀。两相阶段约为 20℃；全部汽化后继续加热，温度才继续升高。

“沸腾时温度不变”有压力不变的前提。定容加热时，不能理解为“先追到一个固定沸点，再永久停在那个温度”。两相共存温度和压力可以配对升高。

定容过程最终是否全部成为气体，取决于装水量和容积；有的路径可能先失去气相，有的可接近临界点。液面发生汽化也不一定表现为内部剧烈冒泡。

这里是热力学思想实验。普通容器不能封死后加热水。

08 / 温度不变，也能改变物态0℃ 降压：液态 → 固态 → 气态

沿图中的 0℃ 竖线，从液态区域缓慢向下降压，在图示范围内可依次经过液态、固态、气态区域。这是纯水、恒温、接近平衡的路径。

普通冰的体积比同质量的液态水大，因此在这段范围内，加压更有利于液态，降压则可让水结冰。再降到足够低的压力，气态更稳定，冰可以升华。

水 → 冰

凝固释放热量，要把热量移走，才能维持 0℃。

冰 → 水蒸气

升华需要能量，要补充热量，才能维持 0℃。

理想恒温缓慢增容时，两相转变可在对应压力上进行，物态比例改变而压力暂时不变。若设备强制继续降低压力，系统可能偏离平衡，就不再是严格的压力平台。

如果没有恒温措施？

温度也会变化，路径不一定竖直。抽气带走蒸气时，汽化可使水冷却；条件合适时可出现结冰，凝固又释放能量；随后冰可能继续升华。实际过程还取决于环境供热、抽气速度与装置，不能只凭“降压”确定全部路径。

09 / 把容易混淆的话改准确检查你的理解

“达到饱和，冰就不能升华了。”

不对。达到饱和时，升华与凝华速率相等。停止的是宏观净变化，不是分子交换。

“凝华后，饱和蒸气压下降了。”

若温度和容积不变，通常下降的是实际水蒸气分压；饱和值基本不变。若冰面温度也改变，才需要重新确定饱和值。

“只要两种物态同时出现，就在相界线上。”

不一定。两种物态可能暂时存在于非平衡过程中；相界线表示两相平衡条件。

“相图上的一个点代表相变完成。”

不对。同一平衡点可有不同物态比例，需要质量、容积或能量等额外信息才能确定。

“所有物态变化都温度不变。”

不对。纯晶体恒压平衡熔化、纯液体恒压平衡汽化可出现温度平台。蒸发冷却、变压相变、非晶体软化等不能直接套用。

“纯水相图要求容器里没有气体。”

不对。水蒸气本身就是纯水的一种物态。要求的是纯物质系统，而不是没有气相或压力为零。

“不加热，就不可能汽化。”

不对。不使用加热器不等于没有能量来源。汽化可以消耗液体自身能量，也可从容器和环境吸热；降压还会改变沸点。

读题时先问三件事：
① 系统是纯水，还是水与空气的混合系统？
② 讨论的是平衡共存，还是正在发生的净变化？
③ 固定的是温度、压力还是体积，能量从哪里来？
